HR Analytics Dashboard

Project Overview
This project presents an interactive Power BI dashboard designed to analyze workforce and employee attrition data.
The dashboard provides insights into headcount, attrition, employee demographics, salary, departments, recruitment sources, and workforce trends.

Business Objective

The objective of this analysis is to:

- Understand overall workforce size and attrition
- Analyze headcount across departments
- Identify employee age distribution
- Analyze attrition trends over time
- Compare workforce composition by gender and marital status
- Evaluate recruitment sources
- Understand salary and workforce demographics

Tools Used

- Power BI
- DAX
- Data Visualization
- Business Analysis

📈 Dashboard Analysis

Department Analysis

Headcount is compared across departments to identify workforce distribution.
Age Analysis

Employees are grouped into age buckets to understand workforce demographics.
Attrition Analysis
Yearly attrition trends are analyzed to identify changes in employee turnover.

Recruitment Source
The dashboard compares employee recruitment sources to understand which channels contribute most to hiring.

Workforce Demographics
Gender and marital status are analyzed to understand employee composition.

Key Insights
- Production has the highest headcount among the departments shown.
- The dashboard records 104 employees under attrition.
- Employee age distribution is concentrated in the 36–45 age bucket.
- Recruitment sources show different levels of contribution to the workforce.
- Attrition trends vary across years, providing an opportunity to investigate employee retention patterns.
